OperaIA Atlas — mind maps, notes and a vault in one calm workspace

A keyboard-first workspace to organize ideas as maps, connect them to notes and a secure vault, and find anything fast.

Client
Own product · productivity
Role
Founder · product design & build
Timeline
2026 · ongoing
Tools
Figma, Vue 3, Vue Flow, Pinia, Fastify, Prisma, PostgreSQL

Outcome

From template to a structured map in seconds, keyboard-first

Context

Thinking tools are either free-form whiteboards that turn into chaos, or rigid document editors. I wanted something in between: the speed of an outline with the overview of a map — plus a place to keep the notes and credentials each project needs.

Problem

  • Mind-map tools are mouse-heavy and slow to structure
  • Maps, notes and “where did I save that password?” live in three different apps
  • Starting from a blank canvas is the hardest part

My role

Founder: concept, interaction design, visual identity and the front end in Vue 3 with Vue Flow, with a Fastify + Prisma API being built alongside.

Process

Define → three verbs for the product: organize, connect, find. Design → a calm, editorial identity (serif headlines, warm accent) and a keyboard model borrowed from outliners. Build → maps on Vue Flow with automatic layout, a map/outline toggle, workspaces, folders, a notes block and a vault. Measure → the goal is time to structure: how fast a blank idea becomes a usable map.

Key decisions

  1. Keyboard first. Tab creates a child, Enter a sibling, F2 renames — the hints are always on screen.
  2. Templates, not blank pages. Project planning, meeting, digital routine and study templates give structure in one click.
  3. Automatic layout with color by branch. You never drag nodes to keep things tidy; each branch keeps its own color.

Outcome

  • Maps with automatic layout, map/outline views, undo/redo and autosave
  • Workspaces, folders, recent maps and a quick notes block on the home
  • A vault for the sensitive bits each project needs, and search across maps, nodes and tags

Learnings

Good defaults beat features: templates plus two keys did more for speed than any toolbar.
